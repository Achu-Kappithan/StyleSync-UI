# UI, Styling & Accessibility Standards

- **WCAG 2.1 AA Compliance**: Use semantic HTML5 elements, keyboard focus indicators, and screen-reader accessible ARIA attributes.
- **Responsive & Touch-Friendly**: Priority design for Tablet/POS and Mobile viewports alongside Desktop.
- **Design Tokens**: Use CSS Variables (`--color-primary`, `--color-bg-dark`, `--font-primary`, etc.) for theme management and dark mode.
- **Naming Conventions**:
  - `kebab-case` for folders and non-component files (`appointment-card.css`, `use-auth.ts`).
  - `PascalCase` for React components (`AppointmentCard.tsx`).
  - `camelCase` for functions and variables (`calculateTotal.ts`).
  - `UPPER_CASE` for global constants (`DEFAULT_TAX_RATE`).
